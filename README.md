# Undergraduate-Physics
I wrote these notes when I was in Highschool primarily to teach myself Physics and typesetting. They are terse, and not a resource you should use to learn for the first time. They may contain grammatical and typesetting errors.
For classical mechanics, I used John Taylor's *Classical Mechanics*. It's a nice place to start from for beginners, but one may find the problems too underwhelming. If you're done with the basics, you can refer to David Tong's lecture notes for *Classical Dynamics*, and then maybe move to more advanced books like Goldstein or Lifshitz and Landau. 
For electrodynamics, my main source was *Introduction to Electrodynamics* by David J. Griffiths. A really nice place to start learning Electrodynamics after highschool. Although I only have ONE problem-- in chapter 5(Magnetostatics), Griffiths presented current as a vector. Although it was brief and only to lend intuition instead of selling it as the truth, as someone who is used to seeing current as $\oint \mathbf{J}\cdot d\mathbf{a}$, it was genuinely unsettling. Other than that, the book is awesome. 
For Fluid Mechanics, I used David Tong's lecture notes. Have not studied any standard books on the topic so far.
All in all, whichever book you choose, I suggest keep Tong's lecture notes at standby for any topic(Field Theory, Mechanics, Dynamics, etc.)
